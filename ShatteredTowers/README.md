# Shattered Towers

A 2D puzzle platformer built with **Godot 4.5** featuring a unique dimension-switching mechanic.

## About the Game

Players switch between two dimensions — **Hope** and **Despair** — affecting platform visibility and level layout. The game incorporates complex gameplay mechanics including:

- Wall sliding
- Jumping & dashing
- Dimension-specific platforms
- Custom shaders for dimension transitions
